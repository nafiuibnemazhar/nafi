Frequently asked

What stack do you default to?

Next.js and Supabase for most full-stack apps, WordPress when the client already runs on it, and Lovable when a client needs to keep editing the UI themselves after handoff.

Do you write the code or just prompt an AI?

Both — I use AI tooling to move fast on boilerplate and first drafts, but architecture, security review, and anything business-critical gets hand-reviewed and often hand-written.

Can you take over an existing codebase?

Yes. Most engagements start with a codebase audit so I understand existing patterns before adding automation or new features on top.
